# Agentic Ops releases

The public release feed for Agentic Ops. An installation reads [releases.json](releases.json) to learn the newest weekly release and next build, even when its GitHub account can no longer read the community repository.

Each weekly release has a short page in [notes/](notes). Members read the full notes, and take updates, from the community repository.

The release train writes this repository. Please do not open issues or pull requests here.
